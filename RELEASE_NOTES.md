# v1.0.0 — research code and numerical data

Author: Chunsheng Li. Original code is MIT; generated numerical data are CC BY 4.0. Download both data-part ZIPs and extract into the source tree. Per-case parameter JSON files are included in the repository; large NPZ fields are in these two non-overlapping ZIPs. SHA-256 values are recorded in RELEASE_ASSETS.json and DATA_MANIFEST.json.

Includes all 21 completed Cartesian cases and separate scalar/CQ benchmarks. Fresh-directory tests reproduced the main complete-field comparisons, representative stationary/spectral quantities and Figures2–5. The numerical model and raw outputs are unchanged. Failed attempts are documented, not counted as successful cases.

These data support the finite-time results under the stated conditions. They do not establish general coupled-system stability, an empirical material vacuum or publication/acceptance by a journal. No DOI has been assigned. Conceptual Figure1 artwork and manuscript text are outside the code/data license scope and are not distributed here.
